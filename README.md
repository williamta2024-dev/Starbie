# Starbie Description
Starbie is a Tamagotchi that has is built around a XIAO ESP32-C3 with an OLED display that displays a cat cahracter.
This project follows the [Starbie Week 1 Guide by SharKingStudios](https://github.com/SharKingStudios/Starbie/blob/main/Week%201%20Guide.md)

## What it does
- Displays an pet on a OLED screen.
- Uses Button 1 to open the menu and confirm actions.
- Uses Button 2 to show or hide the stats screen.
- It reacts to shakes and reads the temperature and humdity.

## Why?
This was created for the first week of [halflife](https://halflife.hackclub.com/).
